SORAYA BIRTHDAY SCRAPBOOK

Open index.html in Chrome or use VS Code Live Server.

Add five photos to images/: her.jpg, memory1.jpg, memory2.jpg, memory3.jpg, puzzle.jpg.
Use exactly these names and extensions. To use PNG/HEIC-converted files instead, change their paths in script.js.

Edit letter and captions in index.html. Edit bingo defaults in script.js.
The envelope, typing intro, bingo and puzzle remain interactive.
Bingo is saved in browser localStorage.
Google Fonts require internet.
Publishing to a public website can expose personal photographs to anyone with access.
